VATSIM Live Gate Occupancy — data.vatsim.net

Important limitation
VATSIM's own data feed does not include a gate field at all — even VATSIM Deparr's public documentation states "gate assignments are not available from VATSIM data." Any gate match here is Dispatch's own inference from position + speed, not ground truth from VATSIM. Treat every result below as a confidence-rated guess, never a guarantee.

VATSIM's public feed (https://data.vatsim.net/v3/vatsim-data.json) refreshes every 15 seconds, no API key required, and gives callsign, lat/lon, altitude, groundspeed, filed aircraft type, and last_updated timestamps. Dispatch improves reliability over a naive single-snapshot check by: (1) filtering to real pilot clients only — excluding ATC/observers, (2) requiring groundspeed <5kt across at least 2–3 consecutive 15s polls before calling a position "settled," (3) discarding any pilot whose last_updated is stale (>30s old, suggesting a dropped/ghost connection), and (4) applying a wider tolerance radius (~60–70m) per gate to absorb scenery/AFCAD offset errors reported across different simulators.

Integration Reference — corrected VATSIM occupancy logic

// Poll history must persist between calls (in-memory cache or DB row per callsign) const pollHistory = new Map(); // callsign -> { count, lastSeen } async function getVatsimOccupancy(icao, gateCoords) { const res = await fetch("https://data.vatsim.net/v3/vatsim-data.json"); const data = await res.json(); const now = Date.now(); const candidates = data.pilots.filter(p => p.groundspeed < 5 && p.flight_plan && // no filed plan is often a ghost/observer artifact isNear(p.latitude, p.longitude, icao, 3) ); candidates.forEach(p => { const ageMs = now - new Date(p.last_updated).getTime(); if (ageMs > 30000) return; // stale feed entry -> treat as ghost, skip const h = pollHistory.get(p.callsign) || { count: 0 }; h.count += 1; h.lastSeen = now; pollHistory.set(p.callsign, h); }); return gateCoords.map(gate => { const occupant = candidates.find(p => distanceMeters(p.latitude, p.longitude, gate.lat, gate.lon) < 70 // widened for scenery offset ); const history = occupant ? pollHistory.get(occupant.callsign) : null; const confidence = !history ? null : history.count >= 3 ? "high" : history.count === 2 ? "medium" : "low"; return { ...gate, occupied: confidence === "high" || confidence === "medium", // low confidence never auto-blocks confidence, callsign: occupant?.callsign || null, aircraft: occupant?.flight_plan?.aircraft_short || null }; }); }

Gate lat/lon reference points must still be curated per airport (OSM's aeroway=parking_position tags are a free starting dataset) — even established tools like vatsim-radar.com need manual per-airport correction for this. Confidence must build over multiple 15-second polls; a single snapshot is never trustworthy as ground truth.
