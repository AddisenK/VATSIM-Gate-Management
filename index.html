VATSIM Gate Management

This project has no visual homepage — it's a single API endpoint that overlays live VATSIM aircraft positions onto real airport gate maps (pulled live from OpenStreetMap) to infer gate occupancy.

Endpoint

GET /api/gates?lat={airport_lat}&lon={airport_lon}

Try it now (Frankfurt / EDDF)

/api/gates?lat=50.0333&lon=8.5706

Response fields

  • gate — gate/stand identifier (from OpenStreetMap)
  • status — "available", "occupied", or "unverified"
  • confidence — null, "low", "medium", or "high" (never treated as ground truth)
  • callsign / aircraft — the live VATSIM flight matched to that gate, if any

Known limitations

VATSIM has no gate field — occupancy is inferred via position matching, not received as fact. OSM gate coverage varies by airport. Multi-poll confidence requires persisted state across requests, which is limited on serverless — see the repo README for details.
